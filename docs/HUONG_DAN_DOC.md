# Hướng dẫn đọc tài liệu — Bắt đầu từ đâu

> Dành cho thành viên mới (hoặc ai quên mất) — đọc đúng theo thứ tự này, đừng nhảy thẳng vào code.

- [ ] **1. `PHAN_TICH_DU_AN_PBL4.docx`** (Chương 1–3) — đề tài giải quyết vấn đề gì, kiến trúc tổng thể, công nghệ dùng. *(File Word, không có trong repo — xin lại link Drive/Zalo nhóm)*
- [ ] **2. `docs/PHAN_CONG_CONG_VIEC.md`** — ai phụ trách khối nào, quy trình làm việc nhóm, ai phụ thuộc dữ liệu của ai
- [ ] **3. `iot/mqtt_data_contract.md`** — định dạng dữ liệu dùng chung giữa 4 khối (MQTT + REST API). **Không đọc file này dễ code sai định dạng, ghép module khác bị lỗi.**
- [ ] **4. `README.md`** — tìm đúng tên mình + đúng tuần hiện tại, đọc checklist "Việc cần làm"/"Kiểm tra" của từng Task. *(Dùng hằng ngày, không phải đọc 1 lần rồi thôi)*
- [ ] **5. `docs/Setup.md`** — hướng dẫn chạy thử toàn bộ hệ thống trên máy (docker compose, chạy backend/ai/frontend)
- [ ] **6. Code trong thư mục khối mình phụ trách** (`iot/`, `backend/`, `ai/`, hoặc `frontend/`) — đọc comment/TODO trong code để biết chỗ nào cần tự viết thêm. Riêng khối AI đọc thêm `ai/MODEL_CARD.md`.

---

Đọc xong cả 6 mục thì mới bắt đầu code — lúc đó sẽ hiểu: **dự án làm gì → mình phụ trách phần nào → 4 khối ăn khớp nhau ra sao → hôm nay cụ thể phải code gì → chạy thử bằng cách nào → code ở đâu**.
